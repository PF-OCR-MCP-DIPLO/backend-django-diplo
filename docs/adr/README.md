# ADRs

Los ADRs documentan decisiones técnicas relevantes del backend.

## Cuándo crear uno

- Cuando cambie la arquitectura de procesamiento.
- Cuando una decisión afecte contratos, seguridad o despliegue.
- Cuando el equipo necesite preservar contexto para futuras rondas.

## Regla de mantenimiento

Si una ADR se deduce solo por la estructura actual, marcarlo como
"Inferida por estructura actual".

Los ADRs activos deben estar enlazados desde `docs/index.md`.
