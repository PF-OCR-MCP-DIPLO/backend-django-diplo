# Operaciones

## Comandos útiles

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
python -m coverage run manage.py test
black --check .
```

## Diagnóstico

- Revisar logs con `LOG_LEVEL`.
- Confirmar conectividad a proveedores OCR/LLM.
- Comprobar `MEDIA_ROOT` para artefactos generados.
