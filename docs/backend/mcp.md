# MCP

`mcp_server` expone herramientas para operar sobre el backend existente.

## Uso

- Consultar estado de jobs
- Iniciar procesamiento
- Exportar resultados
- Leer settings y diagnósticos

## Variables

- `MCP_BACKEND_BASE_URL`
- `MCP_BACKEND_API_TOKEN`
- `MCP_BACKEND_TIMEOUT`

## Limitaciones

- El contrato es local y orientado al backend actual.
- Los tiempos de espera dependen de la carga de procesamiento.
